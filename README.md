GRIDFALL: Last Current is a pixel-art tower defense where every turret draws from one shared 100 W breaker. Build PULSE, ARC, CRYO and TESLA towers around the power core, read the next surge before you deploy it, and keep the grid below the trip point. Six waves, a boss, star ratings, and a breaker that takes five seconds of silence when you overload it.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
